# S1. Core interfaces (about 2 h, $1 cap)

Read CLAUDE.md and docs/01_architecture.md. Build the schemas, router and traces exactly as specified there. Spend cap: $1.

1. Schemas in `loopkit/schemas`: TaskSpec, SkillSpec, ProgramGraph (with `validate(catalog)`), Observation, Verdict, TraceEvent. Export JSON Schema to `loopkit/schemas/json/`.
2. Router in `loopkit/router`:
   - `chat(model_key, messages, images=None, json_schema=None, role=..., max_tokens=..., reasoning=...)`.
   - Adapters: `openrouter` (default), `elorian`, `jev`, `fake`. Copy the request patterns from statebench `backends/llm.py` and `backends/jev.py` and robolabel `providers/` (see docs/06_reuse_map.md). Direct anthropic, openai and gemini adapters are optional, skip them if time is short.
   - Elorian: read platform.elorian.ai's API docs for Glimpse's model id and request format. If it is OpenAI-compatible, use an OpenAI-style adapter with a base_url.
   - Disk cache, retries with backoff, timeouts, spend ledger with projected-cost refusal, `MissingCredentialError` naming the env var.
3. Verify config/models.yaml. For every entry with `verified: false`, look up the id and price in the live OpenRouter catalogue (`GET https://openrouter.ai/api/v1/models`, free) or the provider's docs. Pick `cheap_open`: the cheapest open-weights model on OpenRouter that accepts images and returns JSON, and write down why. Find the Liquid d1 id. Update `source`, `accessed` and `verified`. If something cannot be found, leave it unverified and say so in the report.
4. Traces in `loopkit/traces`: `TraceWriter(run_id)` writes append-only JSONL to `LOOPKIT_DATA/runs/<run_id>/events.jsonl` with images beside it, and `load_runs()` returns a pandas DataFrame with one row per event and flattened model_call fields.
5. Tests with the FakeModel: schema round trips, `validate()` catching at least 6 kinds of bad graphs from the spec, cache hit on a repeated request, ledger refusing a call over cap, trace write and read.
6. Live smoke: one image plus one question ("How many ports have a green LED?" on any test image, or a plain image description) to each model with a key in `.env`. Print a table of model key, real id, latency, input and output tokens, usd and usd_source. Skip models with no key and list them.

Acceptance: tests pass, the live table prints, total spend under $1. Commit. Write reports/S1.md with the table and the models.yaml changes.
