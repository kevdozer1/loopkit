Read CLAUDE.md and docs/03_bakeoff_protocol.md. Build the bake-off runner and report. config/bakeoff.yaml already exists. Spend cap for this session: $5.

1. `loopkit/bakeoff/run.py`: `uv run python -m loopkit.bakeoff.run --config config/bakeoff.yaml [--models ...] [--tasks ...] [--repeats N] [--dry-run]`. For each model, task and repeat, run rehearse-and-patch on the training seeds, then score the final graph on the held-out seeds. For T1 the model is the panel reader, called once per held-out seed. Save to `LOOPKIT_DATA/bakeoff/<date>/` and copy report.md to `reports/bakeoff_<date>.md`.
3. Write `setup/start_bakeoff.ps1`: loads env.ps1, checks the disk floor, starts the full run with `uv run python -m loopkit.bakeoff.run --config config/bakeoff.yaml` writing stdout to `LOOPKIT_DATA/bakeoff/<date>/run.log`, then runs the report. No agent involved.
