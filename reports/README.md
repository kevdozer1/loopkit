# reports

Each session writes `S<n>.md` here: what ran, results with numbers, open issues, and Kevin's exact next action. `PROGRESS.md` is the running status table. `SUMMARY.md` puts the whole S0 to S4 build on one page. Bake-off reports are copied in as `bakeoff_<date>.md`. Headless run logs (`*_run.json`) are gitignored.
